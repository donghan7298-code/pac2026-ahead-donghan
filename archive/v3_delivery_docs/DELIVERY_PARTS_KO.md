# 개별 ZIP 제공본

코드만 확인하거나 GitHub에 올릴 때는 code ZIP을 사용한다. 학습을 재개할 때는 dataset, training_arrays_models, training_shards_01/02/03/04의 ZIP을 모두 같은 폴더에 풀어 PAC2026_Donghan_v3_20261009/ 아래로 합친다. root 파일 SHA256SUMS.txt로 원본 파일을 확인하고 MODEL_14400_GUIDE_KO.md의 relocate → all --resume 순서를 따른다. code ZIP의 학습 안내를 로봇 실행 검증으로 해석하지 않는다. 실제 ROS2/Humble build와 로봇 실행은 아직 확인하지 않았다.
