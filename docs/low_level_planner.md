# 동한 담당 파트 설명

앞 단계가 “놓을 수 있는 후보”를 정하고, 이 파트는 “그중 지금과 이후를 고려하면 어디가 좋은가”를 계산합니다.
결과는 로봇 담당자가 순서대로 검증할 후보 목록입니다.

## 5-③ Feature

OPAL의 15항목은 좌표 x/y/z, 빈 영역 extent 3개, 방향 적용 footprint 2개,
지지율, 지지 중심 여유, 위쪽 높이, 하중 비율, 하중 가능 표시, 측면 지지, 배치 노력입니다.
논문 Table 5의 첫 8개는 원래 격자 단위입니다. 이 구현은 **m 단위**로 바꾸고 별도 정규화 항목을 더했습니다.
EMS가 없을 때 만들어낸 값을 진짜 EMS라고 표시하지 않습니다.

추가 30항목에는 정규화 좌표/치수, 질량, 잔여재고 배치 가능 비율, 버퍼 배치 가능 비율,
버퍼 점유, 하부 의존 수, 위쪽 접근 공간 대용값, CoG 이동·높이 변화, 하중 증가,
조밀도·연속 빈 바닥·단편화·높이 편차, 안전 여유·균형·시간, EMS 유무 등이 있습니다.
실제 순서는 `features.FEATURE_NAMES`와 모델 파일에 함께 고정합니다.

잔여재고 적합도는 수량으로 가중한 제한 후보 탐색 결과입니다. 전체 미래 성공확률이 아닙니다.
버퍼 적합도는 정상 BUFFERED 박스가 후보 배치 후 놓일 수 있는지 검사합니다. 버퍼 행동 선택 자체는 4번의 책임입니다.
접근 공간·작업시간은 로봇 기구학 검증을 대신하지 않습니다.
논문의 stack-load/placement-effort 항은 본 시스템의 정규화된 전체 하중 근거와 시간 대용값에 맞춰 변형했습니다.

## 5-④ AI 평가

작은 NumPy MLP에 두 출력 경로를 둡니다.

- **순위 헤드**: LambdaRank의 NDCG 변화량으로 가중한 pairwise gradient. 같은 결정의 후보 중 Top-K 선정에 사용.
- **값 헤드**: 미래 평균 추가 부피율, 하위 CVaR, 막힘 비율, 미처리 비율을 회귀. 최종 점수의 미래 항에 사용.

예전 115차원/listwise 모델 파일은 새 45차원 계약과 호환되지 않습니다. 기존 가중치를 억지로 로딩하지 않고 다시 학습합니다.
예전 점수기의 안전 포화·공간 품질·공통 미래 표본 아이디어는 유지합니다.

교사는 생성된 유효 후보 **전체**를 같은 미래 표본으로 평가합니다.
학생 학습 후 학생이 방문한 상태를 교사가 다시 라벨링해 누적하는 DAgger/AggrEvaTe 계열의 데이터 집계 방식을 사용합니다.
논문 알고리즘의 완전 재현이나 이론적 성능 보장을 주장하지 않습니다. 현재 실행은 집계 1회입니다.

## 5-⑤ 미래 평가

7개 유형: 무작위 혼합, 큰 박스 후반, 무거운 박스 후반, 작은 footprint 우선,
동일 SKU 연속, 장단비 교차 단편화, 큰 footprint/중량 복합 스트레스.
미입고 수량 비율로 **비복원 추출**하며 스트레스 유형은 제한 horizon 안에 어려운 박스를 포함시킵니다.
순서가 확정된 preview는 모든 시나리오의 앞부분에 그대로 놓습니다.
확인되지 않은 실제 미래 투입순서는 planner 입력에 포함하지 않습니다.

각 후보를 가상 배치한 뒤 미래 박스를 낮은 위치 우선 Greedy로 놓습니다. 매번 원래 Hard Validator를 호출합니다.
미래 박스를 놓지 못하면 그 시나리오는 멈춥니다. 마음대로 버리거나 버퍼에 옮긴 뒤 진행하지 않습니다.

각 시나리오의 값:

`v = 추가로 놓은 미래 박스 부피 / 팔레트 전체 허용 적재부피`

`mean = 평균(v)`, `worst = min(v)`, `CVaR = v의 하위 alpha 확률질량 평균`입니다.
표본 수 × alpha가 정수가 아니면 경계 표본을 비례 반영합니다. 원 논문의 손실 상위 꼬리를 성과 하위 꼬리로 바꾼 것입니다.
`blocking_rate`는 한 번이라도 막힌 시나리오 비율,
`failure_rate`는 horizon 안에서 결국 처리하지 못한 박스 수의 비율입니다.
스트레스 표본이 섞였으므로 이 비율을 실제 공장의 발생확률로 해석하지 않습니다.

Top-K 후보는 같은 시드·같은 시나리오를 공유합니다.
시나리오 하나를 **모든 후보가 끝낸 경우에만** 결과에 반영합니다. 중간 타임아웃이면 그 라운드 전체를 버립니다.
예산 부족 시 K → 시나리오 수 → horizon을 줄이고, 완성된 라운드가 없으면 AI 값 또는 현재 점수로 돌아갑니다.
현재 후보의 필수 검사는 항상 끝냅니다. 외부 콜백의 실행시간을 강제 중단하지 않으므로 1초 hard real-time을 보장하지 않습니다.

## 5-⑥ 최종 점수

```text
Safety = min(1,
             support / target_support,
             cog_margin / target_cog_margin,
             load_margin / target_load_margin,
             pallet_load_margin / target_load_margin)

Space = 0.25 compactness + 0.20 largest_free_patch
      + 0.25 remaining_probe_fit + 0.15 (1 - height_variation)
      + 0.15 (1 - fragmentation)

Risk = (mean - CVaR) + 0.25 blocking_rate + 0.25 failure_rate

Score = w_safety Safety + w_space Space + w_future mean
      - w_risk Risk - w_time normalized_time
```

하드 제약 미달 후보는 점수 계산 대상이 아닙니다.
목표 안전 수준 전에는 가장 약한 안전 여유를 우선하고, 목표를 넘으면 보상이 포화되어 효율 항으로 순위를 결정합니다.
초기 가중치는 YAML에 있으며 최적값이라고 가정하지 않습니다.
검증 데이터에 대해 11가지 ±20% 민감도/Pareto 비교를 제공했습니다.
이 비교는 후보 단위입니다. 전체 작업장 처리량을 최적화한 튜닝으로 표현하지 않습니다.
